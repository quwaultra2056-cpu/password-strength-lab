# Password Strength Lab - Defensive Security

### How long does it take to crack a password?

This is a defensive lab made on Linux on Android (Omdurman / Netherlands).
Goal: To learn how to protect my own systems by understanding weak passwords.

#### What I tested:
- `123456` -> Cracked in < 1 second
- `password123` -> Cracked in ~2 minutes  
- `Omdurman@2026!Secure` -> Takes > 1 million years

#### Lesson Learned:
Strong passwords = Long + Random + Symbols. 
This lab is for EDUCATIONAL DEFENSE only.

#### Tools Used:
- Linux Terminal on Android
- Password strength estimator
